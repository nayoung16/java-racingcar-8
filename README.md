## 구현 기능 목록

### 1. 사용자 입력
- 자동차 이름 목록 입력받기
- 쉼표(,) 기준으로 분리
- 각 이름은 공백이 아니어야 함
- 시도할 이동 횟수 입력받기

### 2. 입력값 검증
- 자동차 이름 유효성 검증 
- 이름이 5자 이하인지 검사 
- 빈 이름(공백 포함) 허용 금지 
- 이동 횟수 유효성 검증 
- 숫자인지 검사 
- 1 이상의 정수인지 검사 
- 잘못된 입력에 대해 IllegalArgumentException 발생 및 애플리케이션 종료

### 3. 자동차 상태 관리
- 자동차 객체 생성 (이름, 현재 위치 포함)
- 복수의 자동차 리스트 초기화

### 4. 라운드 진행 로직
- 0~9 사이의 랜덤 값 생성 
- 랜덤 값이 4 이상일 경우 자동차 전진 처리 
- 주어진 이동 횟수만큼 라운드를 반복 실행

### 5. 진행 결과 출력
- 각 라운드마다 자동차별 전진 결과 출력
- 형식: pobi : ---
- 이름과 함께 현재 위치(‘-’ 개수) 시각화

### 6. 최종 우승자 판별
- 가장 멀리 이동한 자동차(들)의 위치 계산
- 우승자(복수 가능) 이름 추출
- 우승자 출력
- 형식: 최종 우승자 : pobi, jun

### 7. 애플리케이션 흐름 제어
- 전체 게임 실행 흐름 구성
- 입력 → 검증 → 라운드 실행 → 중간 결과 출력 → 우승자 계산/출력
- 예외 발생 시 애플리케이션 종료 처리
